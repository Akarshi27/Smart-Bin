---

## 📌 Overview

Smart Bin is an intelligent waste management system that automatically identifies waste using computer vision and classifies it into the appropriate category. The system combines AI, IoT, and embedded hardware to improve waste segregation accuracy while reducing manual effort.

---

## ✨ Features

- ♻️ Automatic Waste Classification
- 🤖 AI-Based Image Recognition
- 📷 ESP32-CAM Image Capture
- 🧠 CNN-Based Classification
- ⚙️ Servo-Based Automatic Segregation
- 📊 Real-Time Monitoring
- 🌐 IoT Connectivity
- 📱 Smart Dashboard
